# Week 11 - React components, props, state

Topics: creating a React app, built-in vs. custom components, props,
state.

`student-management` is a small React + Vite app: a theme switcher, an
attendance table (toggle each student present/absent), and a student
card list built from reusable `StudentCard` components.

```
cd week11-react-basics/student-management
npm install
npm run dev
```

Open the local URL Vite prints, usually http://localhost:5173/.

For a production build:

```
npm run build
npm run preview
```
