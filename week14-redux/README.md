# Week 14 - Redux, dispatch

A shop cart using Redux Toolkit: `useSelector` to read the cart,
`useDispatch` to send `addItem`, `removeItem` and `clearCart` actions
to the `cartSlice` reducer.

```
cd week14-redux/shop-cart-redux
npm install
npm run dev
```

Open the local URL Vite prints, usually http://localhost:5173/.
