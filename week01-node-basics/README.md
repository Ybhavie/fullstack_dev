# Week 1 - Node.js basics, npm, Express

Topics: installing Node.js, the REPL, project folder structure,
`package.json`, installing Express, creating a server with Express.

## ex1-functions

Plain JavaScript, no dependencies.

```
cd week01-node-basics/ex1-functions
node app.js
```

## ex2-express-server

An Express server with a few routes.

```
cd week01-node-basics/ex2-express-server
npm install
npm start
```

Open in a browser:
- http://localhost:3000/
- http://localhost:3000/about
- http://localhost:3000/home
- http://localhost:3000/contact

See `repl-notes.md` for a quick look at the Node REPL.
