FULLSTACK DEVELOPMENT LAB: HOW TO RUN THE PROJECTS
===================================================

1. WHAT NODE.JS DOES
--------------------
Node.js runs JavaScript in a terminal, outside the browser. A Node program
that starts a web server can send a page or response to a browser. In that
case, keep the server running in the terminal and open its localhost URL in
your browser.

Most exercises in this workspace are terminal programs. They print results
in the terminal and do not open a browser. The Express exercises and the
React/Vite student-management app have browser pages.


2. ONE-TIME SETUP
-----------------
Install the current Node.js LTS release from https://nodejs.org/. npm is
installed with Node.js. In VS Code, open the fullstack_development_lab folder
and open a terminal with Terminal > New Terminal (or Ctrl+`).

Check that Node.js and npm are available:

	node --version
	npm --version

In the terminal, go to the workspace root (the folder containing this
text.txt and the root package.json), then install the root dependencies:

	npm install

The root package provides Express and node-cron for exercises that use them.
The root package does not define a start command, so `npm start` at the root
will not start the labs. Run each exercise from its own folder as described
below. Do not run `npm test` as a start command; the package has a placeholder
test script that intentionally reports an error.


3. RUNNING A TERMINAL-ONLY EXERCISE
----------------------------------
Start in the workspace root, change into the exercise folder, then run its
JavaScript entry file with Node. For example:

	cd .\lab_1\ex_1
	node app.js

The output appears in the VS Code terminal. These exercises do not have a
browser URL. To stop a program that keeps running, press Ctrl+C in its
terminal. To run another exercise, return to the workspace root first:

	cd ..\..

Some exercises read files using paths relative to the current folder. Run
them from the folder shown below so they can find their data files.

5. HOW TO USE A BROWSER WITH A NODE SERVER
-----------------------------------------
1. Start the server command in the VS Code terminal.
2. Wait for a message that says the server is running, or for Vite to print
   its local URL.
3. Open that URL in a browser. Use `localhost`, not a file path. For example,
   `http://localhost:3000/admission` opens the admission route in Lab 4.
4. Keep the terminal open. Closing it or pressing Ctrl+C stops the server.
5. After changing server code, restart it with Ctrl+C and run the command
   again. Vite normally reloads frontend changes automatically.

The browser cannot run a Node `.js` file directly. Use `node app.js` in the
terminal to run Node code. Use a localhost URL in the browser only after a
server has started.


6. COMMON PROBLEMS
------------------
- `node` or `npm` is not recognized: install Node.js LTS, then restart VS Code
  and check `node --version` and `npm --version` again.
- `Cannot find module`: go to the folder containing the relevant package.json
  and run `npm install`. For the root Express/node-cron dependencies, run it
  at the workspace root. For the React app, run it in
  `lab12\student-management`.
- `EADDRINUSE` or a server will not start: another process is using that
  port. Stop the other server with Ctrl+C, or change the port in the exercise.
- The browser says it cannot connect: confirm the server is still running and
  use the exact URL and port printed in the terminal.
- A file is missing: run the command from that exercise's folder, especially
  for file and stream exercises that use relative paths.
- A page looks stale: refresh it. For Node/Express changes, restart the server.


7. QUICK COMMAND REFERENCE
--------------------------
Run a Node script:       node app.js
Install package files:   npm install
Start a package script:  npm start (only where package.json defines it)
Start the React app:     npm run dev (inside lab12\student-management)
Stop a running process:  Ctrl+C in its terminal
Open a server in a browser: http://localhost:<port>/
