# Week 13 - React Router, navigation

A small shop app with three routes and a dynamic product-detail route.

- `/` - Home
- `/products` - Products list
- `/products/:id` - Product detail, read with `useParams`
- `/cart` - Cart
- any other path - a 404 page

```
cd week13-react-router/shop-router-demo
npm install
npm run dev
```

Open the local URL Vite prints, usually http://localhost:5173/.
